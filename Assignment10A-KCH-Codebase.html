Introduction and Overview

In this assignment, the sentiment analysis will be performed in two steps.

In the first, an example workflow from Chapter 2 of Text Mining with R will be replicated Silge and Robinson (2017, chap. 2). The original code and dataset can be accessed in the online book at tidytextmining.com/sentiment.

Then, the analysis will be extended to analyze a different text corpus, specifically the sentiment of WNBA fans in the WNBA subreddit (r/wnba Community 2026). The RedditExtractoR package will be utilized to source the raw comment data, which was developed by Rivera (2023).

Approach

  1. Replicate example workflow from Chapter 2 of Text Mining with R

  2. Source raw r\WNBA comment data using RedditExtractoR

  3. Apply new sentiment lexicons

    1. VADER

  4. Analyze WNBA comment data to identify trends in 2026 Playoffs

Applying sentiment lexicons

Code 
afinn <- pride_prejudice |> 
  inner_join(get_sentiments("afinn"),
             by = join_by(word)) |> 
  group_by(index = linenumber %/% 80) |> 
  summarise(sentiment = sum(value)) |> 
  mutate(method = "AFINN")

bing_and_nrc <- bind_rows(
  pride_prejudice |> 
    inner_join(get_sentiments("bing"),
               by = join_by(word)) |>
    mutate(method = "Bing et al."),
  pride_prejudice |> 
    inner_join(get_sentiments("nrc") |> 
                 filter(sentiment %in% c("positive", 
                                         "negative"))
    ,
    by = join_by(word),
    relationship = "many-to-many") |>
    mutate(method = "NRC")) |>
  count(method, index = linenumber %/% 80, sentiment) |>
  pivot_wider(names_from = sentiment,
              values_from = n,
              values_fill = 0) |> 
  mutate(sentiment = positive - negative)

Proportion of negative words in Chapter 34

Code 
bingnegative <- get_sentiments("bing") |> 
  filter(sentiment == "negative")

wordcounts <- tidy_books |>
  group_by(book, chapter) |>
  summarize(words = n(),
            .groups = "drop")

tidy_books |>
  semi_join(bingnegative,
            by = join_by(word)) |>
  group_by(book, chapter) |>
  summarize(negativewords = n(), .groups = "drop") |>
  left_join(wordcounts, by = c("book", "chapter")) |>
  mutate(ratio = negativewords/words) |>
  filter(chapter != 0) |>
  group_by(book) |>   
  slice_max(ratio, n = 1) |> 
  ungroup()
